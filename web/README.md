# Interfaz Angular de Mesa de Reclamos

Ver el [README principal](../README.md). Comandos:

- `npm install` una vez.
- `npm start`: servidor de desarrollo en http://localhost:4200 (le pasa `/api` y `/soap` a la API en el puerto 5292).
- `npm run build`: compila a `../src/Reclamos.Api/wwwroot`, para que la API sirva la interfaz.
